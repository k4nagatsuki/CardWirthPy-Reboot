### WSNシナリオ形式の仕様変更(Wsn.5)

 * issue #941 / 意識不明者に対しても召喚獣消去効果が確実に適用されるようにした。

### 追加

 * issue #814 / 「荷物袋にあるカードのキャラクターごとの私有を許可する」オプションを追加(デフォルトで有効)。
   CardWirthNextの機能「バックパック」と似ていますが、シナリオの挙動に影響を与えない点が異なります。
    * 私有カードは、データ上は荷物袋にある扱いとなります。
    * 私有カードは荷物袋に属しているため、キャラクターが隠蔽状態であってもキャンプモードで移動する事ができます。
    * 私有カードを持つメンバがパーティから離脱した時には、私有カードはカード置場へ送られますが、次にパーティに属した時は荷物袋へ移して私有状態に戻します。
    * 私有カードは、荷物袋にある他のカードと同様、アイテム欄や召喚獣欄へ一時的に取り出して使用する事ができます。

### 変更

 * issue #896 / 同行キャストの対象消去が完全に機能しない挙動をCardWirth 1.50の互換動作とし、互換モードでなければ完全な対象消去が行われるようにした。
 * issue #915 / `＿１`等の番号クーポンはシナリオ開始エリアに入る直前に付与するようにした。
 * issue #915 / `number_1_coupon`が変更されているスキンでも番号クーポン剥奪時に`＿１`を剥奪対象とするのをやめ、`number_1_coupon_2`が定義されていた場合はそれを剥奪するようにした。
 * issue #869 / シナリオ選択ダイアログで一覧表示中は常に検索欄を表示するようにした。
 * issue #956 / `Resource/Image/Dialog/CAUTION`が存在しない場合でもメッセージダイアログが正常に表示されるようにした。
 * キャラクター情報ダイアログのタブ幅を調節。

### 修正

 * issue #931 / バトルエリア解除時にバトル開始前のエリアが削除されているとエラー。
 * issue #932 / IMEオンの状態でコモンの数値編集欄に不正な値を入力するとエラーが発生する問題を回避。
 * カードの使用時イベントで参照されているJPY1ファイルから参照されているファイルが拠点へ持ち帰られない。

    * `＠使用者`は、カードの使用によって一連のイベントが発生した時、そのカードの使用者に一時的に付与されます。
    * `＠イベント対象`は、死亡イベントやキーコードイベントが発生した時、そのイベントの所有者に一時的に付与されます。
    * `＠効果対象`は、カードの効果対象に一時的に付与され、効果が実際に適用された直後に剥奪されます。このクーポンはシナリオ側での付与・剥奪が可能で、操作の結果は効果対象に反映されます。
      つまり、カードの本来の効果対象であってもキーコードイベントなどで`＠効果対象`を剥奪すると対象から外れ、無関係の者であっても`＠効果対象`が付与されれば対象に入ります。
    * `＠効果対象外`は、実際に対象に効果が適用されはじめた段階で`＠効果対象`を剥奪されたメンバに付与されます。このクーポンを持つメンバには`＠効果対象`をつける事ができなくなります。
      これはターゲットの変更が複雑な状況下で無限ループに陥らないようにするためのもので、通常はこのクーポンを意識する必要はありません。
